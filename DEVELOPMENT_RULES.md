This project strictly written in snake_case, except enums, which are written in SCREAMING_SNAKE_CASE and namespaces, which are written in PascalCase.
When writing classes, name your variables with `m_` prefix (E.g. `int m_hello_world = 5;`) and create read/write functions for them (E.g. `int hello_world() const{ return m_hello_world; }`) if they are public.
Do not write comments, unless they are necessary.
Do not use AI.
Make sure your functions, variables have readable names.
